\addcontentsline{toc}{chapter}{\numberline{}Abstract}
The human brain is always active, even before a person speaks a word. The electrical signals in the brain are already organized and ready before any sound is produced. This project tries to answer whether a machine can read these brain signals and predict what a person is going to say, without actually hearing the sound. Along with this, the project also tries to find out the mental state of the person at that point of time using the same brain signals.This project has two main goals. The first goal is to calculate a cognitive score that shows how mentally active or tired a person is. This is done by looking at different frequency bands in the EEG signal, which are delta, theta, alpha, beta, and gamma. Each of these bands tells something different about the brain's condition. The cognitive score is calculated based on how strong each of these bands is at a given time.\\


The second goal is to decode imagined speech from EEG signals by finding patterns in brain activity that happen during speech articulation, so that the system can predict what word a person was thinking of saying.
To build this system, EEG signals and speech audio are recorded together. The audio is only used to label the data and is not used for prediction. The whole system uses signal processing and machine learning techniques to do both cognitive assessment and imagined speech decoding from a single EEG setup.
